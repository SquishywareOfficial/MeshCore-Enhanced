Install or update over USB

Choose Install via USB. Leave Erase data unchecked to update a compatible MeshCore installation while keeping its saved settings, identity keys and stored data. Updates restart the device, clearing messages held only in RAM. Back up important settings before updating and select your node’s existing role.

For a new device or a fresh start, check Erase data. This erases all settings, identity keys and stored data. These builds are for the original 8 MB XIAO ESP32-S3 with the Wio B2B radio board.

What will this node do?

From USB to your mesh

  1. Connect the kit. Attach its LoRa antenna and use a USB data cable. Close any app or terminal using the serial port. Use desktop Chrome or Edge.
  2. Choose a role and install. Keep Erase data unchecked for an update, or check it for a fresh installation. Select the USB port. If it does not appear, hold BOOT while connecting USB; after installation, reconnect without holding BOOT if needed.
  3. Check or configure your node. Use the MeshCore phone app for a companion, or config.meshcore.io for a repeater or chatroom. After a fresh installation, set your name, passwords and regional radio preset. Enable battery sensing only after fitting the divider.
