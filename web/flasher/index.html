What will this node do?

What MeshCore Enhanced adds

  • Chatroom history that survives restarts. Keep up to 2,000 messages in flash, with a separate catch-up amount (100 by default). Returning users receive missing messages; new users start fresh.
  • Older messages on request. Administrators can replay selected ranges to a logged-in user using saved aliases or public keys, read history over USB and manage saved users. Updated Enhanced companions support older-message replay. History and replay guide ↗
  • USB chatroom bots. Connect a Raspberry Pi or computer directly to the room server. The Python client reads posts and sends replies, with saved progress and sample /bot ping, /bot help and /bot about commands. Bot guide ↗
  • Optional Wi-Fi clock sync. Repeaters and chatrooms can briefly connect at startup or at a chosen interval, with retries and a low-battery guard. Rooms can announce the outcome. Clock guide ↗
  • Configurable peripherals. Battery sensing with a selectable pin and divider calibration across all roles; SHT4x or DHT11 temperature/humidity sensors and digital outputs for repeaters and chatrooms.

Configure these additions through USB or supported authenticated administration commands. See the fork overview and latest release notes and downloads ↗.

From USB to your mesh

  1. Connect the kit. Attach its LoRa antenna and use a USB data cable. Close any app or terminal using the serial port. Use desktop Chrome or Edge.
  2. Choose a role and install. Keep Erase data unchecked for an update, or check it for a fresh installation. Select the USB port. If it does not appear, hold BOOT while connecting USB; after installation, reconnect without holding BOOT if needed.
  3. Check or configure your node. Use the MeshCore phone app for a companion, or config.meshcore.io for a repeater or chatroom. After a fresh installation, set your name, passwords and regional radio preset. Enable battery sensing only after fitting the divider.
