New device or fresh start?

Fresh installation erases saved settings, identity keys and stored data. These buttons install the complete firmware on the original 8 MB XIAO ESP32-S3 with the Wio B2B radio board. An ESP32-S3 chip match alone cannot identify the radio board.

Updating an existing node? Download its application image below and use your supported USB or OTA update procedure. Back up your identity and settings, check the partition layout and active app slot, and verify them afterward. This page does not perform an application-only browser update.

What will this node do?

From USB to your mesh

  1. Connect the kit. Attach its LoRa antenna and use a USB data cable. Close any app or terminal using the serial port. Use desktop Chrome or Edge.
  2. Choose a role and install. Select its USB port. If it does not appear, hold BOOT while connecting USB; after installation, reconnect without holding BOOT if needed.
  3. Configure your node. Use the MeshCore phone app for a companion, or config.meshcore.io for a repeater or chatroom. Set your name, passwords and regional radio preset before deployment. Battery sensing starts off; enable it only after fitting the divider.
